---
name: tranthor
description: Use when the person asks about or wants to work in their connected Tranthor workspace, such as its customer segments, journeys, broadcasts, message templates, drafts, sends, or how its messages and revenue are doing.
---

Tranthor connects you to one Tranthor workspace, as the person who connected it, with their role there. It reads that workspace's customer segments, journeys, broadcasts, message templates and results (revenue, orders and how messages performed). If the person allowed it when they connected, it can also save drafts, pause and resume journeys, and ask the Supervisor, and it can send a broadcast or start a journey after two confirmations. Tranthor's own instructions on the connection say how to use each tool; follow them.

- The person's own instructions come first.
- To find an item, use search, then fetch for its details.
- Answer from what Tranthor returns. If a number is missing or unavailable, say so instead of estimating it.
- When you mention an item, link to it in Tranthor using the link Tranthor returns.
- Never send a broadcast or start a journey without both confirmations: the person approves the preview Tranthor returns, then types its number of customers themselves (for a journey entered by an event, the journey's name). Never type it for them.
- If a tool the request needs is missing, the person's role or the access they allowed does not include it. Say so, and link to the item in Tranthor so they can do it there, or tell them they can connect again to allow more.
