# Tranthor Cursor & Grok Bot Plugin

Official [Tranthor](https://tranthor.com) plugin repository for the Cursor and Grok Bot marketplace, structured from [`cursor/plugin-template`](https://github.com/cursor/plugin-template).

- Marketplace manifest: `.cursor-plugin/marketplace.json`
- Plugin directory: `plugins/tranthor/`
- Remote MCP endpoint: `https://api.tranthor.com/mcp`
